## Acceptance criteria
1. `backend/migrations/006_showcase_views.sql`:
   - Creates regular view `v_driver_season_summary` summarizing driver stats (wins, podiums, points) across championships.
   - Creates materialized view `mv_championship_standings` with `CREATE UNIQUE INDEX IF NOT EXISTS uq_mv_championship_standings ON mv_championship_standings (championship_id, driver_id)`.
2. `backend/migrations/007_audit_log.sql`:
   - Creates `audit_log` table with columns: `id bigserial PRIMARY KEY`, `table_name text NOT NULL`, `op text NOT NULL`, `row_pk jsonb`, `old jsonb`, `new jsonb`, `actor text`, `at timestamptz DEFAULT clock_timestamp()`.
   - Creates `audit_row()` trigger function reading `current_setting('apexgrid.actor', true)`.
   - Attaches trigger to `penalties`, `results`, `pit_reservations`, `championships`.
3. `backend/migrations/008_roles_and_rls.sql`:
   - Creates roles `apexgrid_app` (DML privileges on public tables, sequences) and `apexgrid_readonly` (SELECT privileges).
   - Enables RLS on `audit_log` and adds policy for stewards/admins.
4. `backend/app/schemas_showcase.py`:
   - Implements all Pydantic response models listed in Interfaces, fully typed and strict mypy compliant.
5. `backend/app/api/dbms_showcase.py`:
   - Mounts APIRouter with:
     - `GET /api/dbms/isolation-demo?level=read_committed|repeatable_read|serializable`: runs scripted interleaving on demo row, reports observed reads, timeline, anomaly detection/prevention. Rolls back both connections. Graceful fallback for offline test client.
     - `POST /api/dbms/deadlock-demo`: executes or simulates mutual locking with 40P01 deadlock abort and error details. Graceful fallback for offline test client.
     - `GET /api/dbms/views`: returns view definitions (queries `pg_views` / `pg_matviews` using `pg_get_viewdef` with showcase fallback).
     - `POST /api/dbms/refresh-standings-mv`: executes `REFRESH MATERIALIZED VIEW CONCURRENTLY mv_championship_standings` (with showcase fallback).
     - `GET /api/analytics/gaps?session_id=`: computes window functions (`RANK() OVER`, `FIRST_VALUE`, `LAG`, rolling 3-lap `AVG`), returning gaps list and raw SQL under `sql`.
     - `GET /api/dbms/explain?analyze=true&query_name=`: executes `BEGIN; EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON) ...; ROLLBACK;` for allow-listed query names ("standings_rollup", "lap_telemetry_window", "driver_history").
     - `GET /api/dbms/audit?table=&limit=`: returns rows from `audit_log`.
     - `GET /api/dbms/security`: returns roles, grants, and policies.
6. `backend/app/main.py`:
   - Includes `dbms_showcase_router`.
   - HARD CONSTRAINT: line count of `backend/app/main.py` MUST remain <= 120 lines. (Consolidate health imports if needed to free lines).
