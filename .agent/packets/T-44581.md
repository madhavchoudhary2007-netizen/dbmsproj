     - `/api/sessions/{session_id}/simulate` (POST) -> handler `control_simulation`
   - `live.py`:
     - `/api/ws/sessions/{session_id}` (WebSocket) -> handler `session_ws`
   - `dbms_lock.py`:
     - `/api/dbms/lock-demo` (POST) -> handler `dbms_lock_demo`
     - `/api/dbms/recalculate` (POST) -> handler `dbms_recalculate`
2. Telemetry and database access use `get_race_telemetry` and `get_race_db` via `Depends(...)`.
3. Simulation and bus access use `Depends(get_simulations)` and `Depends(get_bus)` or fallback to app runtime state.
4. Auth dependencies use `admin_steward_dependency = Depends(require_roles("ADMIN", "STEWARD"))` and `admin_dependency = Depends(admin)`.
5. `main.py` directly mounts `app.include_router(simulation_router)`, `app.include_router(live_router)`, `app.include_router(dbms_lock_router)`.
6. Factory functions `create_simulation_router`, `create_live_router`, and `create_dbms_lock_router` remain available and functional for backwards compatibility.
7. Exported aliases on `main.py` (`control_simulation`, `session_ws`, `dbms_lock_demo`, `dbms_recalculate`, etc.) remain accessible for backwards compatibility.
