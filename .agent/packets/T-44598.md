## Task
Ensure the mobile navigation drawer modal properly hides background contents from the accessibility tree when open (Phase 6 / a11y requirement).
In `frontend/components/shell.tsx`:
On the `.main-shell` container element (`<div ref={backgroundRef} className="main-shell">`), add:
`aria-hidden={isMobile && open ? true : undefined}`
`inert={isMobile && open ? true : undefined}`
This ensures that when the mobile drawer is open, the background content (including the topbar and dashboard hero action links) is marked hidden and inert in the accessibility tree according to W3C modal dialog specifications, preventing screen readers and strict-mode element selectors from matching background actions while the modal drawer is active.
Preserve all classes, props, structures, and keep `shell.tsx` strictly < 300 lines (currently 201 lines).
