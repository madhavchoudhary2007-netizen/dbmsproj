1. In `frontend/e2e/race-control-feed.spec.ts`, the test asserts that `.race-control-feed` height is 40px (`expect(await page.locator(".race-control-feed").evaluate((el) => Math.round(el.getBoundingClientRect().height))).toBe(40)`).

5. Verify that BOTH `race-control-feed.spec.ts` (15/15) and `palette.spec.ts` (80/80) pass cleanly.
