1. Create `frontend/components/dbms-showcase.tsx`:
   - Presentational component named `DbmsShowcase` rendering tabs or section panels for DBMS capabilities:
     - Header eyebrow: "DATABASE ENGINEERING / DBMS SHOWCASE"
     - Sub-navigation or view switch: "Isolation", "Deadlock", "Views & MV", "Analytics Gaps", "Query Plans", "Audit & Security".
     - Isolation panel: selector for levels (`read_committed`, `repeatable_read`, `serializable`), "Run Isolation Demo" button (`data-primary`), displays observed reads, timeline steps, and anomaly badge (green/mint "Anomaly Prevented" or red "Non-repeatable Read Detected").
     - Deadlock panel: "Simulate Deadlock" button, displays aborted transaction, SQLSTATE `40P01`, and error details.
     - Views & MV panel: lists `v_driver_season_summary` and `mv_championship_standings` with SQL definition preview; "Refresh Standings MV" button invoking `triggerRefreshStandingsMV()` with duration/status badge.
     - Analytics Gaps panel: session gaps query displaying SQL in a mono paper block and table with driver, lap, position, gap to leader, interval, and rolling average.
     - Query Plans panel: analyze toggle, EXPLAIN plan mono block.
     - Audit & Security panel: table selector, audit logs list (`table_name`, `op`, `actor`, `at`), role grants and RLS policies.
   - Use Neo-Brutal primitives and styling: ink, paper, cream, mint, violet, yellow, red tokens. Touch targets >= 44x44px. Spacing only from 0/4/8/12/16/24/32/48/64px.
   - HARD CONSTRAINT: line count of `frontend/components/dbms-showcase.tsx` MUST be strictly < 300 lines.
