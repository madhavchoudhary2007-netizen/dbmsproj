## Acceptance criteria
1. `race_archive.py` and `laps.py` define domain `APIRouter` (`router`) for:
   - `/api/dbms/races/{session_id}` (GET)
   - `/api/dbms/races/{session_id}/laps` (GET)
   - `/api/sessions/{session_id}/laps` (GET)
2. Database access uses `DatabaseSession` via dependency injection. To preserve compatibility with existing unit tests that monkeypatch `main.fetch_one` / `main.fetch_all`, provide a dependency (e.g. `get_race_db`) that resolves `main.fetch_one`/`main.fetch_all` if they are monkeypatched or if `runtime.pool` is unavailable, and otherwise yields `DatabaseSession(pool)`.
3. Telemetry access uses `Collection[dict[str, Any]]` via dependency injection. To preserve compatibility with existing unit tests that monkeypatch `main.mongo_ready`, provide a dependency (e.g. `get_race_telemetry`) that resolves `main.mongo_ready()` if monkeypatched or available, and otherwise `get_telemetry`.

5. `main.py` directly mounts the router(s) without intermediate positional assembly lambda blocks. `race_history_routes.py` is folded into a thin compatibility wrapper or router export.
6. Exported aliases `dbms_race`, `dbms_race_laps`, `session_laps`, and `race_lap_measurements` remain accessible on `main.py` and `laps.py`.
7. Factory functions `create_race_archive_router` and `create_laps_router` remain available for backwards compatibility.
