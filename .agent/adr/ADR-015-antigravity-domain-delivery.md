## Decision
antigravity.md supplies an explicit dispatch/acceptance contract for requested Gemini3.8Flash HIGH orchestrator and LOW workers, max2. Record actual UI/session evidence or UNVERIFIED. No Markdown claim substitutes for a harness binding; no config/model changes are enacted here.

Keep focused approved worker checks plus independent accept.sh acceptance. No fixed three-second limit. Sensitive integration is root-owned at task scope as required and complete integration closes each domain milestone, not only an entire phase. Preserve final full-suite/score gates unchanged. Use one coherent final-domain tranche; structural8files/800lines is a ceiling. CRUD and simulator lifecycle stay separate unless a recorded concrete dependency requires both. main.py<=120 alone does not complete Phase3. Run an independent ready W1 measured-layout lane alongside W2 when targets do not overlap.

Packets list approved verification/support commands and root integration; the orchestrator compares exact command/task ID before executing an envelope. Explicitly distinguish implemented script checks from manual/model rules and preserve all dirty/owner work. Current execution permission comes from the latest owner request and current state, never a hardcoded historical pause. This request authorizes docs only; it launches no product worker. Capture the existing pending T-44581 packet unchanged as documentation context if included in the documentation acceptance; no product acceptance is implied.

## Consequences
The workflow is more explicit for lower-thinking workers, but no text can guarantee obedience. Real compliance is demonstrated by packet/diff/command/count/integration evidence. New automatic enforcement would require a separate scoped implementation task; no such script is claimed or installed. Full tests, assertions, thresholds, feature/API behavior, two-worker/role boundaries and real-data safety remain unchanged. Open integration debt stays visible, even for accepted static-only refactors.
